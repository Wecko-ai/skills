# Video

Video post-production: audio mastering and captions.

## Model-invoked

Model- or user-reachable: the description tells the model when to reach for them.

- **[youtube-audio-master](./youtube-audio-master/SKILL.md)**: Audit and repair a finished video's audio for YouTube (-14 LUFS, -1 dBTP, clipping, level jumps between blocks) without re-encoding the picture.
- **[karaoke-captions](./karaoke-captions/SKILL.md)**: Word-by-word karaoke caption overlay for vertical videos, the current word popped on a white chip, timed from whisper word timings.
